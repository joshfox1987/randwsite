# **App Name**: R & W Property Solutions Hub

## Core Features:

- Branded Header/Navigation: Display the R & W Property Solutions logo (house icon split vertically with 'R' and 'W'), company name, and a navigation link to the Contact Us section.
- Hero Section: Showcase a banner with the main headline 'WE ARE THE SOLUTION' and a sub-headline describing the company's services.
- Interactive Image Gallery with Auto-Enhance: Enable users to upload images to Firebase Storage, apply automatic CSS/Canvas filters (contrast +10%, saturation +10%, brightness +5%), and display them in a double-decker, auto-scrolling carousel. Includes manual navigation buttons that pause the auto-scrolling.
- Testimonials & Review Section: Display the 2-3 most recent customer reviews and provide a 'View All' feature to reveal all past reviews.
- Review Submission Form: A contact form including Name, Star Rating (1-5), and Comment fields that submits to the Firestore reviews collection.
- Contact Information: Clearly display the company's phone number (as a clickable tel: link) and email address (as a clickable mailto: link).
- AI Chatbot Widget: Implement a persistent, branded AI chat widget in the bottom-right corner to answer basic questions and collect lead information (Name, Phone Number, Service Needed, Preferred Bid Time) and pass it on to a tool so an agent can reach back out.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to evoke a sense of trust, reliability, and clarity, aligning with the professionalism expected for property solutions.
- Background color: Off-white (#F5F5F5), almost the same hue as light blue, but desaturated for a clean, modern base that complements the rugged branding elements.
- Accent color: Dark blue (#00008B), which sits opposite to light blue in a muted but contrasting saturation, highlighting critical interactions and drawing user attention without overwhelming the color scheme.
- Body font: 'PT Sans', a humanist sans-serif providing a modern look with slight warmth suitable for body text, ensuring readability and approachability.
- Headline font: 'Space Grotesk', a modern sans-serif suitable for headlines.
- Use simple, clear icons in black or white to represent different services or features, maintaining a clean and professional look.
- Employ a clean, single-page layout with clear section divisions to present information in a user-friendly manner. Utilize a grid system for consistent alignment and spacing.
